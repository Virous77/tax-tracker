# Bundled chain and token identity data

Ethereum contracts and decimal scales are transcribed from the Etherscan token pages linked below.
This is an identity allow-list, not an endorsement. Symbols are normalised to uppercase for the
ledger. Historical MATIC and MKR remain distinct from replacement contracts; no ticker migration
is inferred. Polygon native POL has MATIC as a historical naming alias.

The Base, Arbitrum One, Polygon PoS and BNB Smart Chain token files are intentionally empty until
verified contract lists are curated for those networks. Unlisted tokens still import using their
chain-scoped contract id. Provider suggestions reflect the Phase 2 research; Base and BNB have no
free default selected while follow-up provider research is in progress.
