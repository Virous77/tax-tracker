# ist-year-boundary

Synthetic data; pending CA review.

18:29 UTC March 31 is 23:59 IST in the old year; 18:31 is 00:01 April 1 in the new year. Prior-year buy cost 100 carries; sale 150 gives gain 50, tax 15.60. Next-year sale 1,000 is ignored.

All INR outputs use half-up rounding at the report boundary. Expected values were written from this arithmetic before the engine was implemented.
